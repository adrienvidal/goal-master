# Plan : Arène

Spec : `docs/specs/2026-11-17-arene-design.md`. Deux PR vers `dev` : d'abord `fix/sprite-poses`, puis `feat/arene`.

**Hors du lot** : autres personnages (Ninja, Guerrière), revanche automatique, historique des combats, animations des Bottes en plein écran, notification à chaque action, réglage des stats depuis l'app.
**Fondrières** : le rejeu du combat (tours, temps morts, étourdissement, parade, potions) → un seul moteur pur testé, rejoué à partir de zéro à chaque lecture, aucun état intermédiaire stocké ; les clics simultanés → action insérée dans une transaction qui revalide le tour et l'énergie, victoire posée par une mise à jour conditionnelle (`winnerId` encore vide).

**PR 1 · `fix/sprite-poses`**
1. Pose Action : l'arme pivote autour du poing (garde et poignée comprises), aucun pixel orphelin ; pose Victoire : l'arme garde sa taille, le bras la brandit (test d'abord dans `sprites.test.ts`).

**PR 2 · `feat/arene`**
2. **Moteur pur `src/game/arena.ts`** (test d'abord) : stats par évolution, échéance, phases, droit de provoquer, énergie, potions, rejeu des tours (temps morts, étourdissement, parade), PV, gagnant au K.O. ou aux points, couronnes, séries pour les succès.
3. **Migration Prisma** `Arena` + `ArenaAction` + `npx prisma generate` ; chargement dans `loadGame`.
4. **Actions serveur** `src/app/arene-actions.ts` : provoquer, répondre, retirer, jouer une action, finir le tour.
5. **Succès** Gladiateur et Coup de maître ; **couronnes** multiples (Défi et Arène).
6. **Notifications** `arena`, `arena-turn`, `arena-end` ; cron quotidien pour les tours passés et la fin au temps.
7. **Sprites** : poses Parade, Potion, Touché, Étourdi, K.O., Victoire + effets et Bottes.
8. **Accueil** : bouton « Arène », panneau, bandeaux, carte compacte.
9. **`/arene`** (scène, actions, journal) et **`/arene/resultat`** avec son observateur.
10. **Intro** : 8e écran, `INTRO_STEP_COUNT` 8, `LATEST_NEWS` « l'Arène ».
11. `npm test`, `npm run build`, parcours local à deux joueurs, PR.
